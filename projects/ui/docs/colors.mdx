# Colors

The library ships a single token sheet, `styles/tokens.css` (published as `dist/ui/styles/tokens.css`).

Cairn is **monochrome**: the brand carries no hue, which leaves semantic color - a gain, a loss, a stale quote - as
the only color in the interface. That is the point of the direction, not a limitation of it: a green figure on a
screen where nothing else is colored is impossible to miss.

Every token declares both of its values with `light-dark()`. The active scheme follows the OS preference, unless the
host application forces one by setting `data-theme="light"` or `data-theme="dark"` on `<html>`.

export const ContrastSwatch = ({ token, ground, ratio, scheme }) => (
  <div style={{ colorScheme: scheme }}>
    <div
      style={{
        height: 44,
        borderRadius: 4,
        border: '1px solid var(--border)',
        background: `var(--${ground})`,
        display: 'flex',
        alignItems: 'center',
        justifyContent: 'center',
        fontWeight: 600,
        color: `var(--${token})`,
      }}>
      Aa
    </div>
    <div style={{ fontSize: 12, marginTop: 4, color: 'var(--muted-foreground)' }}>{ratio}</div>
  </div>
);

## Measured contrast

These ratios were computed, not eyeballed. Every text token clears the WCAG AA threshold of 4.5:1 against all three
possible grounds - `--background`, `--card` and `--elevated`. The tightest values are the ones to watch when editing

- shown here against their worst ground, rendered rather than just quoted so a change to a token shows up here too:

  ['positive', 'background', 'Gain', '4.77:1', '7.76:1'],

`--positive`, `--negative` and `--stale` are **darker in light mode than in dark mode**. This is not an
inconsistency: a mid-tone green that reads at 7.76:1 on a near-black ground only reaches 4.07:1 on white, which
fails. The role is what stays fixed across schemes, never the hex.

## The neutral ramp

`--ramp-1` through `--ramp-6` paint allocation bars. A categorical palette would contradict the monochrome premise,
so luminance is the only variable left; adjacent steps separate by at least 1.44:1 in dark and 1.36:1 in light.
Because each category gets its own bar rather than a segment in a stacked strip, that separation only has to make
the steps distinguishable, never identifiable on its own - the label sits next to every bar.

> `color-scheme`, which is how the whole system switches themes with a single attribute.
